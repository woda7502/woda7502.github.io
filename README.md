# Personal Website

## Overview

This project is a personal website created for **Assignment 1**. The goal of the assignment is to design and publish a fully functional, publicly accessible website using only **HTML and CSS written by the student**, along with the **Foundation 6 CSS framework**. The site presents personal, academic, and professional information in a clean, organized, and responsive format.

The website consists of four main pages—Home, Projects, Resume, and Fun Stuff—and demonstrates core web development concepts such as semantic HTML, consistent styling, navigation, and responsive design.

---

## Installation Instructions

1. **Clone or download the repository**
   ```bash
   git clone https://github.com/woda7502/woda7502.github.io
   ```
   Or download the ZIP file and extract it locally.

2. **Verify project files**
   - `index.html`
   - `projects.html`
   - `resume.html`
   - `fun.html`
   - CSS file(s)
   - Image/media assets

3. **Run locally (optional)**
   - Open `index.html` in a web browser to view the site locally.

4. **Live site**
   - This website is deployed using GitHub Pages and is publicly accessible online.

## Usage Instructions

### Navigation

- A navigation menu appears on each page, allowing users to move between all four sections of the website.
- Links between pages on this site open in the same browser tab.
- Links to external websites open in a new browser tab.

### Pages Included

#### Home (`index.html`)
- Displays a headshot photo
- Includes a short personal introduction (major, interests, and goals)

#### Projects (`projects.html`)
- Showcases at least three academic or personal projects
- Each project includes:
  - A description of the project’s purpose
  - A summary of the work completed
  - At least one image

#### Resume (`resume.html`)
- Resume content written entirely in HTML
- Includes sections such as:
  - Education (with external links to institutions)
  - Work Experience
  - Honors and Awards

#### Fun Stuff (`fun.html`)
- Highlights hobbies, interests, or other personal information
- Includes images, videos, and/or external links

## Design and Technical Details

- Built using **HTML5** and **custom CSS**
- Styled with the **Foundation 6 CSS framework**
- Consistent visual design across all pages
- Responsive layout that adapts to desktop and mobile screen sizes
- Relative paths used for internal links and images
- Scalable font units (e.g., `rem`) used for typography
